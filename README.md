# My Profile (React)

Personal portfolio site built with React, Vite and React Router.

## Run

    npm install
    npm run dev       # local dev server
    npm run build     # production build in dist/

## Editing content

- Projects and screenshots: `src/data/projects.js`
- Social links and nav items: `src/data/links.js`
- Pages: `src/pages/`
- Images: `public/`
